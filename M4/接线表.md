# M4 接线表（重接版）

> 用途：重接、运输前拍照留底、到考核现场恢复。
> **原则：一次只拆一个模块、接一个模块，接完立刻验证。任何时刻都要能回到"已知可用"状态。**

---

## 一、颜色约定（先定好，再动手）

| 颜色 | 用途 | 理由 |
|---|---|---|
| **红** | 6 V（电池正、VM） | 危险电压，红色警告 |
| **黑** | 所有 GND | 地线最多，统一颜色 |
| **橙** | 3.3 V | 逻辑电源 |
| **黄** | STBY | 单根，好认 |
| **绿** | PWMA | PWM 信号 |
| **蓝** | AIN1 | 方向信号 |
| **紫** | AIN2 | 方向信号 |
| **白** | 电机 A 相（AO1） | 到负载 |
| **灰** | 电机 B 相（AO2） | 到负载 |
| 其他 | I2C / 编码器 / 串口 | 按模块分组用同色系 |

**关键：红色只有一根，黑色全是地。** 插错时最先能看出来的就是这两类。

---

## 二、布局（先摆位置，再接线）

```
┌──────────────────────── 面包板 ────────────────────────┐
│                                                        │
│  [STM32 蓝板]        [TB6612]        [MPU6050]        │
│   紧贴左端            紧贴中间        右侧，平放        │
│                                                        │
│        ──── 电源轨（上排 + / 下排 −）────────────────  │
└────────────────────────────────────────────────────────┘
        ↑ 电池盒单独放桌面另一侧，用长线过来
        ↑ 编码器/电机在面包板外侧，线束走同一侧
```

三条规则：

1. **TB6612 紧贴 STM32**，中间不留空，短线就够
2. **电池盒远离面包板**（20 cm 以上），它最重、裸线最多
3. **所有线从面包板同一侧出去**，不要左右各走一半

## 三、接线表（按模块分组）

### 模块 1：ST-Link（下载调试，接板子上的 4 针 Debug 口）

| ST-Link | 板子 | 颜色 | 备注 |
|---|---|---|---|
| 3.3V | 3V3 | 橙 | **板子唯一电源** |
| SWDIO | DIO / PA13 | 黄 | |
| SWCLK | CLK / PA14 | 蓝 | |
| GND | GND | 黑 | |

> ⚠️ **USB-TTL 的 VCC 绝对不要接**，只接 TX/RX/GND。两个电源同时接会冲突。

### 模块 2：USB-TTL（串口，COM11 → WSL /dev/ttyUSB0）

| TTL | 板子 | 颜色 |
|---|---|---|
| TXD | **PA10**（USART1_RX） | 绿 |
| RXD | **PA9**（USART1_TX） | 白 |
| GND | GND | 黑 |
| VCC | **不接** | — |

> TX 接 RX、RX 接 TX，交叉。接反了表现为"板子有电但串口全无输出"。

### 模块 3：MPU6050（I2C1）

| MPU6050 | 板子 | 颜色 | 备注 |
|---|---|---|---|
| VCC | **3.3V** | 橙 | 不要接 5V |
| GND | GND | 黑 | |
| SCL | **PB6** | 绿 | |
| SDA | **PB7** | 蓝 | |
| AD0 | GND | 黑 | 接地 = 地址 0x68 |
| INT | 不接 | — | |

> 上电应打印 `[I2C] found 1 device(s): 0x68`。扫不到就是 SCL/SDA 接反或没共地。

### 模块 4：编码器（TIM3）

| 编码器 | 板子 | 颜色 | 备注 |
|---|---|---|---|
| 蓝（3V3） | **3.3V** | 橙 | **必须 3.3V**，PA6/PA7 不耐 5V |
| 黑（GND） | GND | 黑 | |
| 黄（A） | **PA6** | 绿 | |
| 绿（B） | **PA7** | 蓝 | |
| 红（电机+） | 电机线，接 TB6612 | 红 | 不接板子 |
| 白（电机−） | 电机线，接 TB6612 | 白 | 不接板子 |

> 手转输出轴，`[ENC] total` 应变化；反向转 `total` 减少。

### 模块 5：TB6612FNG（电机驱动）

模块下排（左→右）：`GND BO1 BO2 AO2 AO1 GND VCC VM`
模块上排（左→右）：`GND PWMB BIN2 BIN1 STBY AIN1 AIN2 PWMA`

| TB6612 脚 | 接到 | 颜色 | 备注 |
|---|---|---|---|
| **VM** | 电池盒 **红线 +** | 红 | 6 V |
| **VCC** | 板子 **3.3V** | 橙 | 逻辑电源 |
| **GND**（下排中间，靠 VCC） | 板子 **GND** | 黑 | 逻辑地 |
| **GND**（上排最左） | 电池盒 **黑线 −** | 黑 | 功率地，**必须接** |
| **STBY** | **PB11** | 黄 | 不接则永远待机 |
| **PWMA** | **PB8** | 绿 | |
| **AIN1** | **PB12** | 蓝 | |
| **AIN2** | **PB13** | 紫 | |
| **AO1** | 电机 **红线** | 白 | 转向反了就交换 AO1/AO2 |
| **AO2** | 电机 **白线** | 灰 | |
| PWMB / BIN1 / BIN2 / BO1 / BO2 | **不接** | — | 单电机演示用不到 |

> 两个 GND 都要接，这是电池与单片机的**唯一共地点**。

### 模块 6：按键

| 按键 | 板子 | 备注 |
|---|---|---|
| 任意一脚 | **PA0** | 内部上拉，不用外接电阻 |
| 另一脚 | GND | |

### 模块 7：电池盒

| 电池盒 | 接到 | 备注 |
|---|---|---|
| 红线 + | TB6612 **VM** | 剪掉 PH2.0，裸线拧进杜邦线 |
| 黑线 − | TB6612 **上排 GND** | |

## 四、重接顺序（每步都要验证）

**全程不装电池，直到第 5 步。**

| 步 | 做什么 | 怎么验证 | 通过标准 |
|---|---|---|---|
| 1 | 只保留 ST-Link | 上电 | 串口有 `[BOOT] M4-1 up, SYSCLK = 72 MHz` |
| 2 | 接 MPU6050 | 复位 | `[I2C] found 1 device(s): 0x68` + `[IMU] MPU6050 init OK` |
| 3 | 接编码器 | 手转输出轴 | `[ENC] total` 变化，反转时减少 |
| 4 | 接按键 | 按一下 | `[KEY] DOWN` / `[KEY] UP` |
| 5 | 接 TB6612 信号线（VM 先不接电池） | 复位 | `[MOT] TB6612 ready` 且电机不动 |
| 6 | 量 VM 对 GND = 6 V，再插电池 | 短按按键 | 目标 40 rpm，`rpm` 爬到 40 附近 |

**每步失败就回退这一步，不要带着问题往下接。**

---

## 五、上电前的三项检查（每次都做）

1. **万用表通断档**：VM 与 GND 之间**不能"嘀"**（响 = 短路，停）
2. **目视**：红色线周围 1 cm 内不能有其他裸铜
3. **轻拽**：每根信号线轻拉，拽不动才算插到底

---

## 六、运输

1. 装进鞋盒/纸箱，底部垫泡沫
2. 面包板平放、四周塞紧，**不能晃**
3. 电池盒单独固定在盒子一侧
4. 线束自然躺平，**不要绕圈**（绕圈会产生张力，路上会崩）
5. 盖上写"请勿倒置"
6. **出发前拍三张照片**：面包板俯视、TB6612 特写、电池盒接头特写

---

## 七、现场三步自检

| # | 检查 | 合格 |
|---|---|---|
| 1 | 目视：所有杜邦头插到底、无歪斜 | ✅ |
| 2 | 万用表：VM 对 GND ≈ 6 V | ✅ |
| 3 | 上电：串口出现 `[MOT] TB6612 ready` | ✅ |

三步全过再短按按键试转。
