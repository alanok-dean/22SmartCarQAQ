# 上下位机通信协议 v1.0

> 项目：M4-4 「车与大脑之间的桥」
> 实现：STM32F103C8T6（下位机） ⇄ Linux 主机（上位机，C/C++ + termios）
> 本文是两端实现的**唯一契约**。两端任何一方改字段，必须同步升版本号并更新本文。

---

## 1. 物理层

| 项 | 值 |
|---|---|
| 接口 | USART1（PA9=TX，PA10=RX） |
| 电平 | 3.3V TTL，经 USB-TTL（CH340）接主机 |
| 波特率 | 115200 |
| 帧格式 | 8 数据位 / 无校验 / 1 停止位（8N1） |
| 流控 | 无 |

## 2. 帧结构

```
+--------+-----+---------+-----+-----+-----------+--------+
|  SOF   | VER |   LEN   | MSG | SEQ |  PAYLOAD  |  CRC   |
|  2 B   | 1 B |   2 B   | 1 B | 1 B |  LEN B    |  2 B   |
+--------+-----+---------+-----+-----+-----------+--------+
```

| 字段 | 长度 | 说明 |
|---|---|---|
| `SOF` | 2 | 固定 `0xAA 0x55`。用于逐字节状态机同步 |
| `VER` | 1 | 协议版本，本版为 `0x01` |
| `LEN` | 2 | **载荷长度**（不含头、不含 CRC），小端。上限 `LEN_MAX = 64` |
| `MSG` | 1 | 消息 ID，见 §3 |
| `SEQ` | 1 | 发送方自增序号，`0x00~0xFF` 回绕，仅用于丢帧检测 |
| `PAYLOAD` | LEN | 消息体，长度必须等于 `LEN` |
| `CRC` | 2 | CRC-16 校验值，小端 |

### 2.1 字节序

**全部多字节整数一律小端（Little-Endian，低字节在前）。**
包括 `LEN`、`CRC`、以及载荷内的所有 `int16/uint16/int32`。

> 这是最容易两端不一致的地方：主机 x86 本身就是小端，C 里直接 `memcpy` 就对了；
> 但如果你用 `htons()` 或者手动按大端组包，两边就会"解析出看起来很合理的错误数值"。

### 2.2 CRC 参数

| 参数 | 值 |
|---|---|
| 算法 | CRC-16/CCITT-FALSE |
| 多项式 | `0x1021` |
| 初值 | `0xFFFF` |
| 输入反转（refin） | 否 |
| 输出反转（refout） | 否 |
| 结果异或（xorout） | `0x0000` |
| **覆盖范围** | **从 `VER` 起，到 `PAYLOAD` 最后一字节**（含 LEN/MSG/SEQ，**不含 SOF，不含 CRC 自身**） |
| 网上校验值 | `crc16("123456789") = 0x29B1` |

> 覆盖范围写清楚很重要。若一端从 `SOF` 开始算、另一端从 `VER` 算，
> 两边永远校验失败——而且症状是"帧能收到但全是坏帧"，很难查。

### 2.3 长度上限保护

接收端收到 `LEN > 64` 时：

1. **立即丢弃当前帧**，`bad_frame_cnt++`
2. 状态机回到"找 SOF"，**不按 `LEN` 分配/读取任何缓冲区**

> 没有这条，一个脏字节把 LEN 改成 `0xFFFF` 就能让接收缓冲区越界。

## 3. 消息定义

### 3.1 `0x01` CMD_SPEED（上位机 → 下位机）

目标轮速指令。

| 偏移 | 类型 | 名称 | 单位 | 说明 |
|---|---|---|---|---|
| 0 | int16 | `left_rpm` | r/min | 左轮目标转速，负数=反转 |
| 2 | int16 | `right_rpm` | r/min | 右轮目标转速，负数=反转 |

`LEN = 4`。

### 3.2 `0x02` STATUS（下位机 → 上位机）

状态回报，**固定 50ms 周期**（由定时器驱动，不用 `delay`）。

| 偏移 | 类型 | 名称 | 单位 | 说明 |
|---|---|---|---|---|
| 0 | uint16 | `left_rpm` | r/min | 左轮实测转速 |
| 2 | uint16 | `right_rpm` | r/min | 右轮实测转速 |
| 4 | int16 | `pitch_x10` | 0.1° | 俯仰角 ×10（123 = 12.3°） |
| 6 | uint16 | `heartbeat` | 次 | 下位机心跳计数，每次状态帧 +1 |
| 8 | uint16 | `bad_frame_cnt` | 次 | 累计坏帧数（CRC 错/长度非法/失步） |

`LEN = 10`。

> 姿态角用 ×10 的定点数而不是 float：跨平台没有浮点字节序问题，
> 且板上不做浮点传输，省带宽也省解析成本。

## 4. 示例帧（可独立复算）

### 示例 0：CMD_SPEED，左右各 300 r/min

```
AA 55 01 04 00 01 01 2C 01 2C 01 2B 0F
```

| 字段 | 字节 | 解释 |
|---|---|---|
| SOF | `AA 55` | 帧头 |
| VER | `01` | 版本 1 |
| LEN | `04 00` | 载荷 4 字节（小端） |
| MSG | `01` | CMD_SPEED |
| SEQ | `01` | 序号 1 |
| PAYLOAD | `2C 01 2C 01` | 300 = `0x012C` → `2C 01`，左右各一 |
| CRC | `2B 0F` | CRC = `0x0F2B`（小端） |

**CRC 覆盖的字节**：`01 04 00 01 01 2C 01 2C 01` → 计算结果 `0x0F2B`。

### 示例 1：STATUS，左 298 / 右 301 / 俯仰 12.3° / 心跳 42 / 坏帧 0

```
AA 55 01 0A 00 02 11 2A 01 2D 01 7B 00 2A 00 00 00 51 7C
```

| 字段 | 字节 | 解释 |
|---|---|---|
| SOF | `AA 55` | 帧头 |
| VER | `01` | 版本 1 |
| LEN | `0A 00` | 载荷 10 字节 |
| MSG | `02` | STATUS |
| SEQ | `11` | 序号 17 |
| PAYLOAD | `2A 01 2D 01 7B 00 2A 00 00 00` | 298, 301, 123, 42, 0 |
| CRC | `51 7C` | CRC = `0x7C51`（小端） |

**复算命令**（考官可现场执行）：

```bash
python tools/frame_gen.py --check "AA5501040001012C012C012B0F"
python tools/frame_gen.py --example 1
```

## 5. 接收端状态机（两端一致）

必须**逐字节**驱动，禁止假设"一次 `read()` 拿到一整帧"。

```
WAIT_SOF1 --(0xAA)--> WAIT_SOF2 --(0x55)--> READ_VER
   ^                                          |
   |                                          v
   +----(任何失败)---- READ_CRC <-- READ_PAYLOAD <-- READ_LEN
```

规则：

1. 任意状态收到不符合预期的字节 → **回到 `WAIT_SOF1`**，`bad_frame_cnt++`
2. `WAIT_SOF1` 状态下收到 `0xAA` 之外的字节 → **静默丢弃，不计数**（噪声不属于坏帧）
3. `READ_LEN` 后检查 `LEN > 64` → 丢弃并回 `WAIT_SOF1`
4. CRC 失败 → 丢弃并回 `WAIT_SOF1`，`bad_frame_cnt++`
5. **重同步**：因为每次都从 `WAIT_SOF1` 重新找 `0xAA 0x55`，插入任意脏字节后最多丢弃 1 帧即可恢复，**不会永久失步**

## 6. 健壮性要求（现场会考）

| 破坏手段 | 期望行为 |
|---|---|
| **改错波特率**（一端 115200，另一端 9600） | 两端都不崩；主机侧 `bad_frame_cnt` 快速增长，或直接无有效帧；改回后自动恢复，无需重启 |
| **插入脏字节**（在帧中间/帧间插随机数据） | 最多丢 1 帧，随后自动重同步；`bad_frame_cnt` 增量与插入次数相符 |
| **拔插 USB-TTL** | 主机 `read()` 不空转死循环（`select` 有超时/返回 0 的处理）；重新插上后自动恢复收帧 |

主机侧要点：

- `termios` + `cfmakeraw()`（关闭回显、行缓冲、特殊字符处理）
- `select()` 或非阻塞 `read()`，**禁止裸阻塞 `read()`**
- `read()` 返回 0 或 -1（`EIO`/`ENODEV`）时**不退出进程**，等设备重新出现
- 设备路径与波特率**从命令行传入**：`./upper -d /dev/ttyUSB0 -b 115200`
